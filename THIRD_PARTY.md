# Verwendete Fremd-Software und Inhalte

| Was | Wofür | Lizenz |
|---|---|---|
| [gl-transitions](https://gl-transitions.com) (`gl-transitions.json`) | Profi-Übergänge (WebGL-Shader) | MIT (einzelne Shader BSD) – Autoren siehe Datei |
| [transformers.js](https://github.com/huggingface/transformers.js) (per CDN geladen) | KI im Browser | Apache-2.0 |
| [Whisper](https://github.com/openai/whisper) (Modelle von Hugging Face) | Automatische Untertitel | MIT |
| [MMS-TTS](https://huggingface.co/facebook/mms-tts) (Modelle von Hugging Face) | KI-Stimmen | **CC-BY-NC 4.0 – nur nicht-kommerziell** |
| Google Fonts (Montserrat, Poppins, Bangers, Anton, Bebas Neue, Luckiest Guy, Permanent Marker, Pacifico) | Schriften | SIL Open Font License |
| [myinstants.com](https://www.myinstants.com) | Soundeffekte werden bei Bedarf von dort geladen, nicht mitgeliefert | Inhalte gehören den jeweiligen Urhebern |

Alle eingebauten Beats und Natur-/Comic-Sounds unter „Beats“, „Natur“, „Lustig (eigene)“ und „Übergänge“ werden vom Programm selbst erzeugt.
